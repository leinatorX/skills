# wechat-article-html-style

## 功能定位

`wechat-article-html-style` 用于把已经完成的应急科普公众号文章和图片资产整理成本项目统一风格的本地 HTML 排版页，便于打开预览并复制到微信公众平台编辑器。

## 适用场景

- 将公众号文章转成统一视觉风格的 HTML 发布页。
- 为每期文章整理本地图片引用、正文结构和复制按钮。
- 保持公众号正文排版风格一致，减少每次手动排版成本。

## 使用边界

本技能不负责重新选题、事实核查或正文创作；这些应优先由 `emergency-wechat-writer` 完成。它只处理 HTML 排版、内联样式、本地图片引用、复制到公众号编辑器的兼容性和每期内容文件夹结构。

## 默认产物结构

```text
YYYY-MM-DD-文章主题/
├── 公众号排版版.html
├── 文章标题.md
└── assets/
    ├── cover-*-ai.png
    ├── *-ai.png
    └── ...
```

最终 HTML 和文章成稿应放在本期文章文件夹下；素材参考目录只保存原始参考图、资料或截图。

## 页面要求

- 页面包含本地预览工具层和正文内容层。
- 复制按钮只复制 `<main id="wechatArticle">`。
- 正文核心样式尽量写成内联样式，便于粘贴到微信公众平台后保留主要效果。
- 图片使用相对路径，例如 `assets/cover-storage-tanks-ai.png`。
- 不依赖外部 CSS、CDN、字体、远程脚本或构建工具。

## 视觉风格

- 主色：深蓝黑 `#0f172a`。
- 强调色：安全红 `#b91c1c`。
- 正文字号：`16px`。
- 正文行高：`1.95`。
- 正文最大宽度：`720px`。
- 图片宽度 `100%`，圆角 `8px`，上下留白。

## 交付前检查

- HTML 是否在对应本期文件夹下。
- 图片是否在同级 `assets/` 下，并使用相对路径引用。
- `id="wechatArticle"` 是否只包住要复制到公众号的正文。
- 是否保留复制按钮。
- 是否去掉后台说明、资料依据和内部提示。
- 是否能直接用浏览器打开。
