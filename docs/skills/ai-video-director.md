# ai-video-director

`ai-video-director` 是一个 AI 视频导演工作流 Skill，用于把一句话创意、产品卖点、知识点或剧情想法，整理成可执行的 AI 短视频制作方案。

## 主要能力

- 从一句话扩展创意定位、短视频钩子和情绪曲线。
- 生成短视频剧本、旁白、字幕、对白和结尾记忆点。
- 在剧本完成后提炼人物、道具、场景、风格和关键视觉符号。
- 优先输出定妆照、角色三视图、道具图、场景参考图、风格帧、首帧和尾帧提示词。
- 按 `集 -> 序列 -> 镜头` 规划；序列是 AI 视频生成单位，镜头是成片剪辑单位。
- 判断序列适合文生视频、图生视频、首帧视频、首尾帧视频还是多参考图视频。
- 为每个序列输出三段式视频提示词，并为镜头输出剪辑区间和剪辑备注。
- 默认视频模型使用 Grok Imagine Video，默认图像模型使用 GPT Image 2。
- 为 Veo、Seedance、Runway、Sora、Kling、Grok Imagine Video 等模型改写提示词。
- 为 GPT Image 2 和 Nano Banana Pro 输出参考资产提示词。
- 按抖音、小红书、B站、视频号、YouTube Shorts、TikTok、快手等平台输出发布包装建议。
- 检查 AI 视频生成结果，给出可用、可修、重生成或弃用判断。

## 使用示例

```text
使用 ai-video-director，把“一个消防机器人在暴雨夜救援被困司机”扩展成 15 秒抖音 AI 短视频剧本、定妆照提示词、序列级 Grok 视频提示词和镜头剪辑表。
```

```text
使用 ai-video-director，帮我把这个产品卖点改成小红书 20 秒种草视频方案，并输出 Runway 图生视频提示词。
```

## 边界

- 默认不直接调用视频生成 API。
- 涉及最新模型能力、图像模型参数或官方提示词指南时，应联网核对官方资料。
- 平台爆款逻辑只作为内容优化参考，不保证播放量、涨粉或转化。
- 涉及广告、医疗、金融、未成年人、危险动作、版权和肖像时，需要单独做合规复核。
