# yingji-linglingqi-knowledge-graph

## 功能定位

`yingji-linglingqi-knowledge-graph` 是应急凌凌漆专用的应急、消防、危化、安全生产科普知识图谱闭环技能，用于把安全主题做成适合抖音、小红书、公众号图文发布的中文知识图谱内容包。

## 适用场景

- 做一期应急、消防、危化、安全生产相关知识图谱选题。
- 围绕安全主题完成资料调研、事实核验和分图方案。
- 输出逐张图的中文出图提示词。
- 生成或复核知识图谱成图。
- 输出抖音、小红书、公众号风格发布文案、标题、标签和置顶神评。
- 从立项、调研、方案、提示词、出图、自检到发布文案做完整闭环。

## 工作流

按用户需求选择最小必要流程；用户要求完整闭环时按以下顺序执行：

1. 立项判断：确定主题类型、目标人群、平台、传播目标和风险边界。
2. 资料调研：核验数字、编号、标识、颜色、代码、等级、类别、法规和流程。
3. 知识图谱方案：选择高流量模型，规划分图结构，明确每张图的传播任务。
4. 图文脚本：写主标题、副标题、一级节点、二级节点、底部警示和尾图互动。
5. 出图提示词：为每张图写可直接执行的中文提示词。
6. 成图落盘：出图完成后保存到当前项目目录下的主题文件夹。
7. 成图自检：检查画幅、中文、知识准确性、传播漏斗、信息密度、收藏点和互动门槛。
8. 发布文案：输出标题、正文、置顶神评、标签和 SEO 关键词，并写入主题目录。

## 关键规则

- 数字、编号、标识、颜色、代码、等级和类别类主题，必须先给具体答案。
- 主题目录必须使用 `YYYY-MM-DD-主题名` 命名，日期为立项日期，主题名使用具体主题词。
- 图 1 负责点击，不能写成“XX 是什么 / XX 类型 / XX 作用 / XX 知识图谱”。
- 图 2 负责留人，不能只讲定义、分类、组成和正常功能介绍。
- 中间图必须有收藏价值，优先做识别表、对照表、流程卡、巡检清单、口诀卡、红黑榜。
- 尾图必须留白，互动问题要让非专业用户也能回答。
- 不要写成工程报告、说明书或政策公文。

## 交付结果

完整闭环任务默认交付：

- 立项结论。
- 调研核验。
- 知识图谱总方案。
- 分图脚本。
- 逐图出图提示词。
- 生成前自检。
- 成图落盘与画幅核验。
- 成图复核标准。
- 发布文案包与落盘文件。
- 风险与后续建议。
