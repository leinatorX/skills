# emergency-wechat-writer

## 功能定位

`emergency-wechat-writer` 用于应急、消防、危化、安全生产、城市安全、防灾减灾等领域的微信公众号内容创作，覆盖选题策划、标题、摘要、封面方案、正文配图方案、正文成稿和发布前自检。

## 适用场景

- 应急科普公众号、安全科普推文、消防公众号和危化科普文章。
- 标准、法规、政策、通知的大白话解读。
- 事故新闻后的专业解释和非猎奇复盘。
- 企业合规提醒、城市安全、防灾减灾和安全生产管理类文章。
- 已有文章的去 AI 化、改写、润色和发布前自检。

## 工作流

默认先输出策划方案，不直接写完整长文，除非用户明确要求“直接成稿”。

1. 核实资料：涉及法规、标准、政策、事故、新闻、数据时，先查官方资料或要求用户提供来源。
2. 输出策划：包含选题判断、推荐标题、文章主线、大纲、封面图建议、正文配图建议、发布建议和待确认问题。
3. 用户确认后成稿：输出标题、摘要、正文、小标题、重点加粗建议、配图插入位置、结尾总结、转发引导和标签建议。
4. 发布前自检：检查事实依据、表达红线、封面适配、正文可读性和转发理由。

## 注意事项

- 事实类内容不能凭记忆编写，必须区分已确认事实、合理判断和仍需核实的信息。
- 不夸大事故，不渲染血腥、伤亡、爆炸等敏感画面。
- 专业内容要准确，但表达要让普通读者读得懂。
- 公众号封面图和正文知识图可以直接要求生成清晰中文文字；如果出现错字、漏字或乱码，优先重生成。
