# 剧本与分镜设计

## 剧本结构

短视频剧本应优先服务留存，而不是完整电影式铺垫。

### 15 秒结构

```text
0-3 秒：钩子，直接给冲突、结果、反差或强视觉。
3-10 秒：递进，展示过程、证据、变化或危险升级。
10-15 秒：高潮或结论，给反转、答案、行动或循环点。
```

### 30 秒结构

```text
0-3 秒：钩子。
3-8 秒：建立人物、问题或场景。
8-20 秒：冲突升级或信息递进。
20-27 秒：解决、反转或视觉高潮。
27-30 秒：记忆点、行动号召或循环回看。
```

## 分镜设计原则

- 一个镜头只表达一个主要动作或信息。
- 开头镜头必须有明确主体和明确变化，避免空镜铺垫太长。
- AI 不稳定时，把复杂动作拆成多个 2-4 秒短镜头。
- 人物口型、手部、群体动作、复杂物理交互容易失败，需要降低复杂度。
- 角色连续出现时，每个镜头都重复稳定特征：发型、服装、脸型、材质、关键道具。
- 角色、产品、品牌、道具或主场景需要连续出现时，优先图生视频，不要只靠文生视频维持一致。
- 动作起点和终点都重要时，优先规划首尾帧。
- 需要剪辑的镜头不要把所有信息塞满，给转场、字幕和音效留空间。

## 分镜类型

### 剧情短片

使用“冲突递进”：

```text
异常出现 -> 主角反应 -> 危机升级 -> 选择动作 -> 结果或反转
```

### 产品展示

使用“问题-产品-证据-结果”：

```text
痛点画面 -> 产品出现 -> 功能演示 -> 使用前后对比 -> 购买/了解理由
```

### 知识科普

使用“误区-解释-示范-结论”：

```text
常见误解 -> 关键原理 -> 可视化演示 -> 一句话总结
```

### 视觉奇观

使用“尺度升级”：

```text
局部细节 -> 主体变化 -> 大场面展开 -> 震撼收束
```

## 分镜提示词模板

```text
镜头 {编号}，{时长} 秒，{画幅}。
画面目标：{这个镜头要让观众感受到什么}。
画面内容：{主体} 在 {场景} 中 {动作}，{环境元素} 发生 {变化}。
景别：{特写/近景/中景/远景/广角/微距/监控视角}。
构图：{三分法/对角线/引导线/黄金分割/荷兰角/主体位置/前景背景关系}。
运镜：{固定/推/拉/摇/移/跟拍/手持/第一人称/变焦}。
光线和风格：{光线、色彩、质感、影像风格}。
声音：{对白、旁白、环境声、音效、音乐要求}。
生成方式：{文生视频/图生视频/首帧视频/首尾帧视频/多参考图视频}。
参考资产：{角色定妆照/场景图/道具图/风格帧/首帧/尾帧}。
负面约束：避免 {不想要的错误}。
```
